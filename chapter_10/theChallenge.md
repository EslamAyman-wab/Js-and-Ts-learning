# Chapter 10 - Higher Order Functions

هذا الملف يجمع تكليفات الدوال عالية المستوى مثل `map`, `filter`, و `reduce`.

---

## التكليف 01 - استخراج الحروف من Array

### المطلوب

- لديك متغير `mix` يحتوي على حروف وأرقام.
- إنشاء Array جديدة باستخدام `map`.
- استثناء الأرقام من النتيجة.
- دمج الحروف للوصول إلى كلمة `Elzero`.
- استخدام `map` و `reduce`.
- عدم استخدام `join` أو `filter`.

```js
let mix = [1, 2, 3, "E", 4, "l", "z", "e", "r", 5, "o"];

// Elzero
```

---

## التكليف 02 - إزالة الحروف المكررة

### المطلوب

- لديك النص `myString`.
- إنشاء Array جديدة باستخدام `filter`.
- إزالة الحروف المكررة.
- دمج الحروف للوصول إلى كلمة `Elzero`.

```js
let myString = "EElllzzzzzzzeroo";

// Elzero
```

---

## التكليف 03 - تحدي Flatten بدون flat

### المطلوب

- لديك Array بداخلها Array أخرى.
- استخدام `reduce` لعمل Flatten.
- دمج الحروف للوصول إلى كلمة `Elzero`.
- عدم استخدام `Array.flat()`.

```js
let myArray = ["E", "l", "z", ["e", "r"], "o"];

// Elzero
```

---

## التكليف 04 - عكس إشارات الأرقام

### المطلوب

- لديك Array تحتوي على أرقام وحروف.
- استخدام `filter` و `map`.
- استثناء الحروف من النتيجة.
- تحويل الموجب إلى سالب والسالب إلى موجب.

```js
let numsAndStrings = [1, 10, -10, -20, 5, "A", 3, "B", "C"];

// [-1, -10, 10, 20, -5, -3]
```

---

## التكليف 05 - تحدي reduce

### المطلوب

- لديك Array تحتوي على أرقام زوجية وفردية.
- استخدام `reduce` فقط للوصول إلى الناتج.
- تعيين `Initial Value` بقيمة `1`.
- إذا كان الرقم فرديًا، اجمعه مع الـ `Accumulator`.
- إذا كان الرقم زوجيًا، اضربه في الـ `Accumulator`.

```js
let nums = [2, 12, 11, 5, 10, 1, 99];

// 500
```

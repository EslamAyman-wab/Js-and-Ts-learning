# Chapter 07 - Loops

هذا الملف يجمع تكليفات الفصل السابع الخاصة بالتكرار باستخدام `for`, `while`, والتحكم في التكرار باستخدام `break` و `continue`.

---

## التكليف 01 - الطباعة مع استثناء رقم

### المطلوب

- عدم استخدام الأرقام يدويًا.
- استخدام قيم المتغيرات فقط.
- طباعة الأرقام من `10` إلى `100`.
- استثناء الرقم `40`.
- استخدام `for loop`.

```js
let start = 10;
let end = 100;
let exclude = 40;
```

### الناتج المطلوب

```text
10
20
30
50
60
70
80
90
100
```

---

## التكليف 02 - العد التنازلي مع صفر قبل الرقم

### المطلوب

- عدم استخدام الأرقام يدويًا.
- طباعة الأرقام تنازليًا حتى الرقم `3`.
- إذا كان الرقم أصغر من `10` اطبع صفرًا قبله.
- استخدام `for loop`.

```js
let start = 10;
let end = 0;
let stop = 3;
```

### الناتج المطلوب

```text
10
09
08
07
06
05
04
03
```

---

## التكليف 03 - Nested Loop

### المطلوب

- عدم استخدام الأرقام يدويًا.
- طباعة الرقم الأساسي ثم أرقام داخلية كما في المثال.
- استخدام `for loop`.

```js
let start = 1;
let end = 6;
let breaker = 2;
```

### الناتج المطلوب

```text
1
-- 2
-- 4
2
-- 2
-- 4
3
-- 2
-- 4
4
-- 2
-- 4
5
-- 2
-- 4
6
-- 2
-- 4
```

---

## التكليف 04 - التحكم داخل Loop فارغة

### المطلوب

- عدم استخدام الأرقام يدويًا.
- كتابة الكود داخل الـ `for` فقط.
- عدم تعديل أي شيء خارج الـ `for`.

```js
let index = 10;
let jump = 2;

for (;;) {
  // Write Your Code Here
}
```

### الناتج المطلوب

```text
10
8
6
4
```

---

## التكليف 05 - طباعة الأسماء مع استثناء حرف

### المطلوب

- عدم استخدام الأرقام أو الحروف يدويًا داخل الحل.
- طباعة الأسماء التي لا تبدأ بحرف `A`.
- وضع رقم قبل كل اسم بطريقة ديناميكية.
- استخدام `for loop`.

```js
let friends = ["Ahmed", "Sayed", "Eman", "Mahmoud", "Ameer", "Osama", "Sameh"];
let letter = "a";
```

### الناتج المطلوب

```text
"1 => Sayed"
"2 => Eman"
"3 => Mahmoud"
"4 => Osama"
"5 => Sameh"
```

---

## التكليف 06 - تبديل حالة الحروف

### المطلوب

- عدم استخدام الأرقام أو الحروف يدويًا.
- تحويل الحروف الكبيرة إلى صغيرة والصغيرة إلى كبيرة.
- استخدام `for loop`.

```js
let start = 0;
let swappedName = "elZerO";
```

### الناتج المطلوب

```text
"ELzERo"
```

---

## التكليف 07 - طباعة الأرقام فقط

### المطلوب

- عدم استخدام الأرقام يدويًا.
- طباعة الأرقام فقط.
- تجاهل الرقم `1`.
- استخدام `for loop`.

```js
let start = 0;
let mix = [1, 2, 3, "A", "B", "C", 4];
```

### الناتج المطلوب

```text
2
3
4
```

---

## التكليف 08 - While Loop مع فلترة

### المطلوب

- عدم استخدام الأرقام يدويًا.
- عدم طباعة الأرقام الموجودة داخل المصفوفة.
- عدم طباعة الأسماء التي تبدأ بحرف `A`.
- استخدام `while loop`.

```js
let friends = ["Ahmed", "Sayed", "Ali", 1, 2, "Mahmoud", "Amany"];
let index = 0;
let counter = 0;
```

### الناتج المطلوب

```text
"1 => Sayed"
"2 => Mahmoud"
```

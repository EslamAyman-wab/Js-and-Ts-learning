# Chapter 17 - Set, Map, Spread, And copyWithin

هذا الملف يجمع تكليفات هياكل البيانات الحديثة في JavaScript مثل `Set` و `Map`، مع استخدام `Spread Operator` وبعض طرق الـ Array.

---

## التكليف 01 - إنشاء Set

### المطلوب

- إنشاء `Set` جديدة باسم `setOfNumbers`.
- إضافة الرقم `10` أثناء الإنشاء.
- إضافة الرقم `20` في سطر منفصل.
- في نفس السطر السابق، إضافة عنصر جديد يساوي عدد عناصر الـ Set قبل الإضافة.
- طباعة الـ Set.
- في سطر منفصل، طباعة آخر عنصر موجود داخل الـ Set.

### الناتج المطلوب

```text
Set(3) {10, 20, 2}
2
```

## التكليف 02 - إزالة التكرار والترتيب

### المطلوب

- لديك Array تحتوي على أسماء أصدقاء وبعضها مكرر.
- طباعة الأسماء مرتبة أبجديًا وبدون تكرار.
- تنفيذ الحل في سطر واحد فقط.

```js
let myFriends = ["Osama", "Ahmed", "Sayed", "Sayed", "Mahmoud", "Osama"];

// Needed Output
// (4) ["Ahmed", "Mahmoud", "Osama", "Sayed"]
```

## التكليف 03 - تحويل Object إلى Map

### المطلوب

- تحويل Object إلى `Map`.
- طباعة محتوى الـ Map.
- طباعة عدد عناصر الـ Map.
- فحص هل تحتوي الـ Map على العنصر `role`.

```js
let myInfo = {
  username: "Osama",
  role: "Admin",
  country: "Egypt",
};

// Needed Output
// Map(3) {"username" => "Osama", "role" => "Admin", "country" => "Egypt"}
// 3
// true
```

## التكليف 06 - تحدي copyWithin

### المطلوب

- لديك Array تحتوي على أرقام وحروف.
- عدد الأرقام الموجودة يحدد عدد الأحرف التي سيتم نسخها.
- جعل الأرقام تأتي في بداية الـ Array بغض النظر عن مكانها.
- نسخ أول أحرف مكان الأرقام.
- الحل يجب أن يعمل حتى لو تغيّر عدد الأرقام أو أماكنها.

### أمثلة

```js
let chars = ["A", "B", "C", "D", "E", 10, 15, 6];
// Needed Output: ["A", "B", "C", "A", "B", "C", "D", "E"]

let chars = ["A", "B", "C", 20, "D", "E", 10, 15, 6];
// Needed Output: ["A", "B", "C", "D", "A", "B", "C", "D", "E"]

let chars = ["Z", "Y", "A", "D", "E", 10, 1];
// Needed Output: ["Z", "Y", "Z", "Y", "A", "D", "E"]
```

### توضيح الفكرة

```js
let chars = ["A", "B", "C", "D", "E", 10, 15, 6];
// بعد نقل الأرقام للبداية:
let chars = [10, 15, 6, "A", "B", "C", "D", "E"];
// بعد نسخ أول 3 أحرف مكان الأرقام:
let chars = ["A", "B", "C", "A", "B", "C", "D", "E"];
```

## التكليف 08 - تحدي الرقم 210

### المطلوب

- لديك Arrays تحتوي على أرقام.
- الوصول إلى الرقم `210`.
- عدم استخدام الأرقام ولا `true` ولا `false`.
- عدم استخدام Indexes لجلب أي رقم من الـ Arrays.
- عدم استخدام Loops أو Higher Order Functions.
- الحل في سطر واحد فقط.
- إذا استخدمت `length` يجب استخدامها مرة واحدة فقط.
- إذا استخدمت عملية حسابية فالمسموح فقط هو الضرب `*`.

```js
let n1 = [10, 30, 10, 20];
let n2 = [30, 20, 10];

// Needed Output
// 210
```

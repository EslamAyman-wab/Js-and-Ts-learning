## الجزء الأول - Number Methods

### التكليف 01 - طباعة الرقم 100000 بطرق مختلفة

#### المطلوب

- طباعة الرقم `100000` بثلاث عشرة طريقة مختلفة.
- كل طريقة يجب أن تكون مختلفة عن الأخرى.
- استخدام العمليات الحسابية مرة واحدة فقط.

```js
// Examples
console.log(100_000); // 100000
console.log(100000); // 100000
console.log(5e4 + 5e4); // 100000

// Your Solutions
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
console.log(); // 100000
```

### التكليف 04 - استخراج أرقام من نص

#### المطلوب

- من المتغير التالي، اطبع الرقم `100` وتأكد أن نوعه `Number`.
- في السطر الثاني، اطبع الرقم `100.57` وتأكد أن نوعه `Number`.

```js
let myVar = "100.56789 Views";

console.log(); // 100
console.log(); // 100.57
```

## الجزء الثاني - String Methods

### التكليف 01 - جلب أول حرف

#### المطلوب

- جلب أول حرف من النص بست طرق مختلفة.
- عدم تكرار الحلول.
- استخدام المتغير فقط.
- التأكد أن الحرف صغير.
- أحد الحلول يجب أن يكرر الحرف ثلاث مرات.

```js
let userName = "Elzero";

console.log(); // e
console.log(); // e
console.log(); // e
console.log(); // e
console.log(); // e
console.log(); // eee
```

---

### التكليف 02 - التحقق من وجود الحروف

#### المطلوب

- التأكد أن الحرف `Z` موجود داخل الكلمة وتكون النتيجة `true`.
- التأكد أن الكلمة تبدأ بالحرف `E` وتكون النتيجة `true`.
- التأكد أن الكلمة تنتهي بالحرف `o` وتكون النتيجة `true`.
- الانتباه لحالة الأحرف الكبيرة والصغيرة.
- عدم التلاعب بقيم المتغيرات.

```js
let word = "Elzero";
let letterZ = "z";
let letterE = "e";
let letterO = "O";

console.log(); // true
console.log(); // true
console.log(); // true
```
